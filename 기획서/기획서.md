# 한 장 기획서 — 스도쿠

**형태:** 윈도우 단독 실행형 (.exe 파일 하나, 설치 불필요, 오프라인 동작)

**한 문장 설명:** 짧은 시간에 두뇌 게임을 즐기려는 사람이 쓰는 스도쿠 프로그램.

## 기능
- **핵심 (1개):** 스도쿠 퍼즐 자동 생성과 플레이 (같은 행·열·3x3 칸에 중복되면 바로 표시)
- **부가 (3개):** ① 난이도 선택(쉬움/보통/어려움) ② 힌트(횟수 제한) ③ 난이도별 최단 시간 기록 저장

## 완료 기준 (3개)
1. 새 게임마다 풀 수 있는 퍼즐이 생성되고, 끝까지 풀면 완료 메시지가 뜬다.
2. 설명서 없이 처음 보는 사람이 마우스와 키보드만으로 플레이할 수 있다.
3. `.exe` 파일 하나로 다른 PC에서 실행되고, 시연 중 멈추거나 꺼지지 않는다.

## 안 할 것 (3개)
1. 온라인 대결, 랭킹, 로그인 등 네트워크 기능
2. 모바일 앱·웹 버전
3. 스도쿠 외의 다른 게임 모드, 과한 테마 꾸미기

## 후보와 선택 이유
후보: D-day 플래너, 시간표 겹침, 포켓몬 도감, 가계부, 뽀모도로, 플래시카드, 파일 이름 변경기, 스도쿠 중 선택.
→ 규칙이 직관적이라 설명 없이 쓸 수 있고, 시연 효과가 좋으며, 8시간에 맞는 크기라서 스도쿠로 결정.

*기술: Python + tkinter, PyInstaller로 .exe 빌드 / 실행 중 AI API 호출 없음, 개인정보 없음*
