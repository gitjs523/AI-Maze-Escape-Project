# 한 장 기획서 (초안) — AI 추격 미로 탈출

> 초안 (2026-11-20). 스도쿠 기획서를 대체할 후보. 자정 전에 최종 선택.

**형태:** 윈도우 단독 실행형 (.exe 파일 하나, 설치 불필요, 오프라인 동작)

**한 문장 설명:** 쉬는 시간에 가볍게 게임을 즐기려는 학생이, 길을 찾아 쫓아오는 AI 추격자를 피해 미로의 출구까지 탈출하는 게임.

## 기능
- **핵심 (1개):** 매 판 새로 생성되는 미로에서, 길찾기(A*) AI 추격자가 벽을 돌아 플레이어를 쫓아오고, 잡히기 전에 출구에 도착하면 다음 단계로 진행
- **부가 (3개):**
  1. **단계별 난이도 상승:** 미로 크기, 추격자 수와 속도, 추격 방식(직선 추격, 길목 차단, 순찰 후 추격)이 단계마다 달라짐
  2. **아이템과 시야:** 손전등으로 보이는 범위가 제한되고, 속도 증가, 추격자 잠깐 멈추기 같은 아이템이 있음
  3. **기록과 통계:** 최고 단계, 클리어 시간, 도전 횟수를 로컬 파일에 저장

## 완료 기준 (3개)
1. 새 게임마다 출구에 갈 수 있는 미로가 생성되고, 추격자가 벽을 피해 최단 경로로 쫓아오며, 잡히면 게임 오버, 출구에 닿으면 다음 단계로 넘어간다.
2. 설명서 없이 방향키만으로 30초 안에 시작해 이해할 수 있다 (첫 화면에 조작 안내 한 줄).
3. `.exe` 하나로 다른 PC에서 실행되고, 시연 중 멈추거나 꺼지지 않는다.

## 안 할 것 (3개)
1. 온라인 대결, 멀티플레이, 랭킹 서버
2. 외부 그림·음원 사용 (도형과 간단한 효과로만 구성 — 저작권 문제 방지)
3. 스토리 모드, 별도 맵 에디터

## 깊이의 근거 (3주 분량)
- 미로 생성 알고리즘 (DFS, 프림 등)과 출구 도달 가능성 검증
- 길찾기 AI(A*)와 추격 방식 여러 종류 구현
- 난이도 곡선 설계, 시야(손전등) 렌더링, 기록 저장

## 전시회 시연 계획
- 첫 화면에서 키 한 번으로 시작 → 쫓기는 긴장감이 30초 안에 전달됨
- "AI가 길을 찾는 모습"은 잡힌 뒤 추격 경로를 보여 주는 장면으로 시각화 가능

## 기술과 위험
- Python + pygame-ce (Python 3.14용 설치 확인됨), PyInstaller로 .exe 빌드. 실행 중 AI API 호출 없음 (추격 AI는 직접 구현한 알고리즘), 개인정보 없음
- 위험: 실시간 조작감과 난이도 밸런스, pygame-ce의 .exe 빌드 → **구현 첫날 시험 빌드를 먼저 한다**
