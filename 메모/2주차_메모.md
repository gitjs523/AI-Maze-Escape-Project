# 2주차 메모 (2026-11-27)

> 다음 주(12/04)에는 새 대화를 열고 이 파일부터 읽는다. 주제는 "AI 추격 미로 탈출" (스도쿠는 `sudoku/`에 보존만 함).

## 오늘 한 일
1. `maze/logic.py`: 미로 생성(DFS + 우회로 약간), A* 길찾기, BFS 거리 — 화면과 분리한 순수 로직
2. `maze/main.py`: pygame-ce 게임. 방향키/WASD 이동, A* 추격자, 출구 도착 시 다음 단계, 잡히면 게임 오버(추격자가 따라온 길을 주황 선으로 표시), 제목 화면
3. 단계별 난이도: 미로가 커지고 추격자가 빨라짐(0.30초→최소 0.15초/칸), 4단계부터 추격자 2명
4. 자동 테스트: `python -I maze/test_logic.py`, `python -I maze/test_game.py` (미로 연결성 200개, A*가 BFS 최단과 일치, 가만히 있으면 잡힘, 단계 진행 등)
5. exe 빌드 성공: `dist/AI추격미로.exe` (약 29MB), 다른 폴더에 복사해 실행 → 5초 이상 유지 확인

## 확인된 것 / 아직 안 된 것
- 확인: 화면 캡처(제목/플레이/게임 오버) 정상, 한글 표시 정상(맑은 고딕), exe 실행 유지
- **사람이 직접 해 봐야 하는 것**: 키 조작감(이동 속도 0.11초/칸), 난이도 느낌(1단계 직진 로봇은 24/40 탈출), 4단계 이상
- 제목 화면에서 R 키는 무시됨(의도). 일시정지는 없음

## 알려진 한계 (3주차 후보)
- 추격자가 항상 최단 경로로만 와서 단조로움 → 계획서의 "길목 차단, 순찰 후 추격" 추격 방식 추가
- 부가 기능 3개(단계 난이도 다듬기, 아이템·손전등 시야, 기록 저장)는 아직 없음
- 화면 배율(DPI) 점검 필요 (스도쿠 때 메모와 동일)
